# Filters and Search

## Search
Search should match the user's expected identifiers: name, ID, email, document number, title, etc.
Tell users what can be searched when ambiguity is high.

## Filters
Use visible filters for common dimensions.
Use advanced filter panels for infrequent combinations.
Show active filters clearly.
Provide a predictable reset action.

## Persistence
Persist filters when users repeatedly return to the same working view and persistence is useful.
Do not surprise users with invisible stale filters.

## Results
Always distinguish:
- no data exists
- no results match current filters
- search failed
