# Mobile Adaptation

Do not treat mobile as a scaled-down desktop.

## Re-prioritize
Identify:
- must-see information
- must-do actions
- secondary context

## Patterns
- stack regions vertically
- move secondary controls into sheets/drawers
- keep primary actions thumb-reachable
- use bottom sheets for short contextual actions when appropriate
- preserve task state across navigation

## Tables
Convert according to user task; do not simply hide random columns.

## Forms
Use mobile-native input types and avoid dense multi-column forms.
