# Navigation

Navigation should reflect the user's mental model and task frequency.

## Global navigation
Use sidebar when:
- there are several stable product areas
- users switch areas frequently
- desktop use dominates

Use top navigation when:
- there are few primary destinations
- content width matters more than persistent modules

Use bottom navigation on mobile only for 3-5 genuinely top-level destinations.

## Local navigation
Use tabs for sibling sections of the same object or settings domain.
Do not use tabs for sequential workflow steps.

## Context preservation
For record-heavy work, consider a detail drawer or split view when users must inspect many rows without losing filters and scroll position.

## Breadcrumbs
Use when hierarchy is deep or object context can be lost.
Do not add breadcrumbs to shallow apps by habit.
