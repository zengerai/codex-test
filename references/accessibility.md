# Accessibility

Accessibility is part of product quality.

## Baseline
- semantic HTML
- keyboard navigation
- visible focus
- sufficient contrast
- labels for controls
- error text connected to fields
- status not communicated by color alone
- appropriate target sizes
- respect reduced-motion preferences

## Complex components
For dialogs, menus, comboboxes, tables, tabs, and popovers, prefer proven accessible component primitives over hand-rolled behavior.
