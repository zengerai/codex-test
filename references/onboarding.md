# Onboarding

Onboarding should lead to first meaningful value, not merely explain features.

## Prefer
- minimum required setup
- progressive onboarding
- sample/demo data when it accelerates understanding
- checklist only when tasks are genuinely useful
- resume support for unfinished setup

## Avoid
- long carousels before the user can try the product
- forcing optional personalization early
- asking for information before explaining why it is needed
