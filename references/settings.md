# Settings Pages

Settings should be predictable, grouped, and reversible where possible.

## Structure
Group by user mental model:
- account/profile
- team/organization
- permissions
- integrations
- notifications
- billing
- security
- advanced

Use local navigation when groups are numerous.

## Save behavior
Choose one model and be consistent:
- immediate autosave
- explicit per-section save
- whole-page save

Do not mix models without clear reason.

## Dangerous actions
Separate destructive account/org actions visually and semantically.
Require appropriate confirmation and explain consequences.
