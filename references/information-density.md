# Information Density

Density should match task frequency and comparison needs.

## Use higher density when
- the user works in the product for hours
- many records must be compared
- batch actions are common
- users already know the domain
- context switching is expensive

Use:
- tighter vertical rhythm
- concise labels
- aligned columns
- grouped actions
- compact controls
- stable placement of repeated elements

## Use lower density when
- the user is new
- tasks are infrequent or high-stakes
- one decision needs attention
- content is emotional or explanatory
- mobile is primary

## Avoid false spaciousness
Do not add large empty regions merely to look premium.
Operational products benefit from visible context and reduced scrolling.

## Scannability
Group by meaning, not decoration.
Use alignment, spacing, typography, and separators before adding containers.
A border/card should communicate grouping, hierarchy, or interaction.
